# Vitamouv

Site vitrine pour une éducatrice sportive intervenant auprès de collectivités et de particuliers.  
Développé en **ASP.NET Core 8**.
Le projet inclut un formulaire de contact fonctionnel, un design responsive en CSS + Bootstrap et un déploiement complet sur Render avec domaine personnalisé.

## 🚀 Fonctionnalités
- Formulaire de contact avec **Brevo**
- Validation client + serveur (AJAX + Razor)
- Design responsive avec Bootstrap
- SEO : sitemap, robots.txt, meta tags
- Déploiement Render + domaine `vitamouv.fr`

## 🛠️ Stack
- **Backend :** ASP.NET Core 8  
- **Frontend :** HTML, CSS, JavaScript  
- **Emailing :** Brevo
- **Déploiement :** Render  
- **Domaine :** IONOS  

## 📦 Installation
```bash
git clone https://github.com/cvitali/Vitamouv.git
cd Vitamouv
dotnet restore
dotnet run
```

## Variables d'environnement
